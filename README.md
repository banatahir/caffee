# کافێی ئێمە — ماڵپەڕی v3 (کوردی سۆرانی، RTL)

ماڵپەڕی ستاتیک (`public/`) + سێرڤەری بچووکی Node (`server/`) بۆ ئیمەیڵ، تێلێگرام، نیوزلێتەر و ڕای Google.

## دەستپێکردن
```bash
npm install
cp .env.example .env     # OWNER_EMAIL و (ئارەزووی) SMTP / تێلێگرام پڕ بکەرەوە
npm start                # http://localhost:3000
npm run check            # وێنە و بەستەری شکاو دەدۆزێتەوە
```
بێ سێرڤەریش کار دەکات: لە `public/js/config.js` بنووسە `apiUrl: false` — هەموو فۆرمەکان بە واتسئەپ دەنێردرێن.

## پەڕەکان
`index` سەرەکی · `menu` مێنیو · `gallery` گاڵەری · `about` دەربارە + پرسیارە باوەکان · `reserve` حیجز · `contact` پەیوەندی + نەخشە · `404`

| کاتی حیجز/وەرگرتن | تەنها ڕۆژ و کاتی کراوە نیشان دەدرێت؛ ڕۆژی داخراو و کاتی ڕابردوو خۆکارانە نامێنن |
| سەبەتە | لەسەر هەموو پەڕەکان؛ ناردن بە سێرڤەر یان نامەی ئامادەکراو بە واتسئەپ |

| ئاگادارکردنەوە | ئیمەیڵ + **تێلێگرام** (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`) + وەڵامی خۆکار بۆ کڕیار |
| ڕۆژژمێر | دوای حیجز، فایلی `.ics` بۆ زیادکردن بۆ ڕۆژژمێر |
| دڵخوازەکان، دۆخی تاریک | لە وێبگەڕ دەمێننەوە؛ دۆخی تاریک لەگەڵ سیستەم خۆکارانە |
| PWA | `manifest` + `sw.js`: لەسەر مۆبایل دادەمەزرێت و بێ ئینتەرنێتیش دەکرێتەوە |

| بڵاوکردنەوە | `.github/workflows/pages.yml` — پشکنین + دیپلۆی بۆ GitHub Pages |
| سپام | honeypot، سنووری ٢٠ داواکاری/١٥ خولەک، helmet + CSP |

## پێش بڵاوکردنەوە
1. `public/js/config.js` — مۆبایل، واتسئەپ، ئیمەیڵ، ناونیشان، نەخشە، ئینستاگرام (هەموو `REPLACE`ەکان).
2. `npm run domain -- https://دۆمەینەکەت` و بەشی JSON-LD ی `index.html` (ناونیشان).
3. `public/js/menu-data.js` — **نرخەکان نموونەن**؛ هەستیاربوونەکان (شیر/گلوتین/هێلکە) لەگەڵ ڕێسێپتی ڕاستەقینە بپشکنە.
4. `.env` — `OWNER_EMAIL`، SMTP، `SITE_URL`.
5. وێنەی ڕاستەقینەی کافێ: لە `public/img` دایبنێ و `npm run images`.
